# Adiscon Community

This repository is the public roadmap and feedback hub for selected Adiscon Windows products. It is the place for roadmap items, feature requests, roadmap feedback, and UI wording or translation suggestions.

Useful starting points:

- Adiscon: https://www.adiscon.com/
- rsyslog: https://www.rsyslog.com/
- WinSyslog: https://www.winsyslog.com/
- EventReporter: https://www.eventreporter.com/
- MonitorWare Agent: https://www.mwagent.com/

## What this repo is for

- Public roadmap items for selected Adiscon Windows products
- Feature requests and roadmap discussion via GitHub Issues
- Product-feedback signals that help prioritization
- UI text customization, wording, and translation suggestions

## Products covered by the roadmap

- WinSyslog (Windows syslog server; first syslog server for the Windows platform, released in 1996)
- EventReporter (Windows Event Log forwarding; first Windows Event Log-to-syslog forwarder, created in 1997)
- MonitorWare Agent (actively developed Windows monitoring + log processing suite)
- rsyslog Windows Agent (Windows companion for rsyslog users)
- Adiscon LogAnalyzer discussions may still appear here, but the roadmap focus is on the Windows product line listed above

## How the roadmap works

- Roadmap items are tracked as GitHub issues
- A GitHub Project provides the public roadmap views
- Issues stay readable and discussable in the open
- Labels describe stable metadata such as product, type, and area
- Timeline and release-window planning belong in GitHub Project fields, not in labels

See also: [docs/public-roadmap-setup.md](docs/public-roadmap-setup.md)

Current public roadmap:

- https://github.com/orgs/Adiscon/projects/11

This roadmap is a communication and prioritization tool, not a hard delivery promise.

## What this repo is not

- This is not a product source code repository. Do not submit product source code here.
- This is not an official support channel. For product support, licensing, or operational issues, please use Adiscon’s support channels.
- This is not the roadmap for rsyslog core.

## Where to go for what

- Roadmap: use the public roadmap project above
- Roadmap and feature ideas: open an issue in this repository
- Roadmap feedback: open a roadmap feedback issue in this repository
- UI wording or translation suggestions: open a UI wording / translation issue in this repository
- Product support and licensing: use Adiscon's official support channels
- Security issues: use the private reporting instructions in [SECURITY.md](SECURITY.md)
- rsyslog core topics: use the rsyslog project channels, repository, and documentation

Useful links:

- Adiscon support: https://www.adiscon.com/support/
- rsyslog project: https://github.com/rsyslog/rsyslog
- rsyslog site: https://www.rsyslog.com/

## Contributing

Please keep contributions within scope: roadmap items, feature requests, roadmap feedback, UI customization resources, and language file improvements.

For language files, do not change keys or file structure. Only propose improvements to translated text values and preserve formatting.
